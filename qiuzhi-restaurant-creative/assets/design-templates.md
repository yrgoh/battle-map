# Design Templates for Restaurant Promotional Materials

## Poster Layout Patterns

### Pattern 1: Hero Image + Centered Text
```
┌─────────────────────────────────┐
│                                 │
│    [BACKGROUND: Vintage wood]   │
│                                 │
│      ═══════════════════        │
│         HEADLINE (CN)           │
│         HEADLINE (EN)           │
│      ═══════════════════        │
│                                 │
│    [Body copy in center box]    │
│    [with aged paper texture]    │
│                                 │
│         OFFER BADGE             │
│      (circular/stamp style)     │
│                                 │
│     📍 Location · ☎ Contact     │
└─────────────────────────────────┘
```

**Best for**: Grand opening, major announcements
**Color scheme**: Warm browns, cream, burnt orange accent

## EDM (Email) Layout

### Structure
```
Header Image (600px width)
├── Logo + Tagline
│
Greeting Section
├── Personal opening line
│
Hero Content
├── Main promotional image/banner
├── Headline (larger font)
├── Subheadline
│
Body Sections (responsive blocks)
├── What's Special (with icons)
├── The Offer (highlighted box)
├── Story/Heritage Note
│
Call-to-Action
├── Button (warm color, rounded)
├── "Visit Us" / "Reserve Now"
│
Footer
├── Location + Map link
├── Social media icons
├── Unsubscribe link
```

### Best Practices
- Max width: 600px for compatibility
- Single column for mobile responsiveness
- Clear hierarchy: headline > image > body > CTA
- Buttons: 44px height minimum (touch-friendly)
- Alt text for all images

## Typography Recommendations

### Headlines
- **English**: Bebas Neue, Oswald, League Gothic (bold, condensed)
- **Chinese**: 文鼎粗黑 (Arphic Bold), 思源黑体 (Source Han Sans Bold)
- **Vintage style**: Clarendon, Rockwell, Courier Bold

### Body Text
- **English**: Lora, Merriweather, Georgia (readable serif)
- **Chinese**: 思源宋体 (Source Han Serif), 宋体 (SimSun)
- **Modern option**: Inter, Open Sans (clean sans-serif)

### Accent/Script
- **English**: Pacifico, Dancing Script, Satisfy
- **Chinese**: 行楷 (Xing Kai), 华文行楷 (STXingkai)

## Visual Elements Library

### Icons & Illustrations
- ☕ Coffee cup (simple line art)
- 🍞 Toast icon (vintage style)
- 🏠 Shophouse silhouette
- 🌅 Sun rays (nostalgic warmth)
- ★ Stars (ratings, special offers)
- 🎫 Ticket/coupon perforated edge

### Decorative Borders
- Double-line classic frames
- Corner flourishes (Art Deco style)
- Dotted/dashed separators
- Bamboo or rattan pattern borders

### Textures (Subtle Overlays)
- Aged paper (light brown, ~10% opacity)
- Wood grain (warm tone, ~15% opacity)
- Canvas fabric (neutral, ~5% opacity)
- Coffee stain rings (accent, ~20% opacity)

## Image Format Specifications

### Poster
- **Digital Display**: 1080x1350px (4:5 ratio), PNG, 72 DPI, RGB
- **Print**: A3 (297x420mm), 300 DPI, CMYK, JPG high quality

### Flyer
- **Digital**: 1748x2480px (A5 at 300 DPI), PNG or JPG, RGB
- **Print**: A5 (148x210mm), 300 DPI, CMYK, PDF preferred

### EDM
- **Email**: 600px width, variable height, JPG optimized (~150KB)
- **Banner**: 600x300px, PNG with transparency if needed
- **CTA Button**: 2x resolution for retina (e.g., 300x88px @2x)

## Design Principles

1. **Hierarchy**: Headline > Visual > Body > CTA (clear reading flow)
2. **Whitespace**: Don't overcrowd - let elements breathe
3. **Contrast**: Dark text on light background for readability
4. **Authenticity**: Use genuine vintage elements, avoid fake distress
5. **Bilingual Balance**: Equal visual weight for English and Chinese
6. **Cultural Sensitivity**: Respectful representation, not caricature
